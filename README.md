# Used Car Price Prediction

A machine-learning project for exploring and predicting used-car resale prices.

## Project files

- `Used Car Price Prediction.ipynb` — notebook with the analysis and model workflow.
- `Used Car Price Prediction.html` — HTML version of the project.
- `Used Car Price Prediction.docx` — project report.
- `cardata.csv` — car data used by the project.
- `carpricemodel.pkl` — serialized trained model.

## Open the notebook

Open `Used Car Price Prediction.ipynb` in Jupyter Notebook or JupyterLab. The notebook uses Python with pandas, NumPy, Matplotlib, and scikit-learn.

Only load `carpricemodel.pkl` from a source you trust; Python pickle files can execute code when loaded.
